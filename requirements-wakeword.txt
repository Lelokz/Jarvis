# Jarvis — Etapa 0.5, experimento de wake word
#
# SEPARADO do requirements.txt de propósito: isto é um experimento. Se o
# modelo pronto não passar no teste do Léo, some daqui sem tocar na Etapa 0.
#
# ATENÇÃO — a instalação NÃO é um `pip install -r` direto.
#
# O openwakeword 0.6.0 declara `tflite-runtime` como dependência dura no
# Linux, e o último release dela (2.14.0, nov/2023) só tem wheel até cp311.
# No Python 3.12 a instalação normal falha. Como o import do tflite é
# preguiçoso e usamos `inference_framework="onnx"`, ele nunca é tocado —
# então instalamos sem as dependências e trazemos as reais à mão:
#
#     pip install --no-deps openwakeword==0.6.0
#     pip install requests==2.34.2 "scipy>=1.3,<2" "scikit-learn>=1,<2"
#
# scipy e scikit-learn não são usados na inferência, mas o
# openwakeword/__init__.py importa custom_verifier_model no topo, e esse
# módulo importa os dois. Sem eles nem dá para importar o pacote.
#
# Versões conferidas em 2026-09-02.

openwakeword==0.6.0
requests==2.34.2
scipy==1.18.1
scikit-learn==1.9.0
